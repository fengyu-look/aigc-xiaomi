# 提示词语言库分类导航

按 9 个创作用途分类，另设完整合集资料区和完全重复副本区。分类日期：2026-10-05。

原有 60 个文件全部保留原文、格式和文件名，其中 51 份内容不完全相同，9 份是哈希完全相同的额外副本。不同排版或不同内容版本均保留。原文件本身未删改。分类完成后，已另建一站式创作小秘工作库，保留完整原文并增加MD应用扩写；完整合集的61库也各有独立工作入口。

## 用于以后的内容创作

日常先看 [一站式创作小秘入口](91_创作小秘工作库/00_工作入口.md)，包含15类咨询模块、61库扩写章节和51份原文映射。技能名为 `$film-creation-library`。以下分类保留原始TXT，供追溯。

[创作使用指南](00_创作使用指南.md) 提供整体用法；[旧版原TXT检索索引](00_语言库检索索引.json) 继续保留原文件章节位置。

## 创作顺序与分类边界

建议按：剧本与大纲 → 图片与参考资产 → 分镜 → 视频生成 → 声音音乐 → 剪辑后期。人物表演、特效和商业广告按需要调用。

- 图片制作：包含角色、场景、道具资产提取和形象图，以及构图、光线、材质等共同参考。
- 分镜制作：负责把故事组织为镜头、设计动作与空间关系；兼容直接输出生成提示词的分镜工具。
- 视频生成提示词：以生成模型可直接执行的完整提示词、生成控制与反提示词为主要用途。
- 电商与商业广告：集中保存完整商业工作流；其中商品全套图也属于图片制作，带货和广告也属于视频生成。
- 基础语言库按实际用途放入对应分类，避免另设一个过大的“基础库”目录。每份文件只放一个主分类，跨用途通过下方链接查找。
