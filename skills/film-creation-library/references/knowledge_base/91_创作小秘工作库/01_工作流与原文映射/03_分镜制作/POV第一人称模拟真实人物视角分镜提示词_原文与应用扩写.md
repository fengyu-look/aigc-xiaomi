# 逻辑一致性校验系统

## 逻辑链 1｜动作因果链
- 每个动作必须有前因、执行、结果。
- 禁止结果先于原因。
- 禁止动作无触发。
- 禁止动作跳跃。
- 示例：先看到门虚掩（因）→ 停住呼吸（反应）→ 伸手推门（执行）→ 门轴响（结果）→ 视线进入客厅（新状态）。

## 逻辑链 2｜空间关系链
- 物体与物体之间、人物与人物之间、人物与物体之间的位置必须自洽。
- 禁止同一物体在同一时间出现在两个位置。
- 禁止物体穿透另一物体。
- 禁止人物穿过墙体、门板、家具。
- 禁止物体漂浮无支撑。
- 禁止影子方向与光源方向矛盾。
- 禁止遮挡关系在同一分镜内反转而无动作解释。

## 逻辑链 3｜物理规律链
- 重力方向一致。
- 物体下落、滚动、倾倒符合物理。
- 液体流动方向正确。
- 布料下垂方向正确。
- 头发、衣摆、烟雾、尘埃运动方向与风、呼吸、动作一致。
- 光源照射方向与高光、阴影方向一致。
- 禁止物体凭空出现或消失。
- 禁止手穿过物体。

## 逻辑链 4｜时间顺序链
- 子镜头时间轴必须严格递增。
- 每个动作必须在合理时长内完成。
- 禁止动作时长与速度矛盾。
- 禁止同时发生互斥动作。
- 禁止上一子镜头未结束的动作在下一子镜头凭空完成。
- 眨眼、呼吸、心跳、吞咽必须按真实生理节奏分布。

## 逻辑链 5｜人物交互链
- 人物与人物之间的视线、动作、对话、距离必须自洽。
- 禁止两人同时占据同一空间。
- 禁止一人对另一人动作无反应。
- 禁止对话口型与声音方位矛盾。
- 禁止人物身份、服装、外貌在同一分镜内变化。
- 禁止多人场景人物数量突变。
- 禁止人物关系错误。

## 逻辑链 6｜数量与身份链
- 每个分镜中人物数量、物体数量必须明确且一致。
- 禁止人物数量增减无解释。
- 禁止物体数量增减无解释。
- 禁止同一人物被描述为不同身份。
- 禁止背景人物突然消失或出现。
- 禁止镜像、倒影中人物数量与实体矛盾。

# 第一人称 POV 物理约束系统

# 宏观提示词强制规则
每个分镜必须单独写“宏观提示词”，用于控制整段视频的风格、时代、情绪、色彩、光线、声音基调。宏观提示词必须与原文匹配，并在同一分镜内保持稳定。若剧情内发生时代跳跃、回忆、梦境、想象，必须明确标注宏观提示词切换的时间点与切换后的新宏观设定。
