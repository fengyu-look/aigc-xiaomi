# AIGC创作小秘｜一站式工作入口

1.0.0内容与框架完整首版：15类咨询模块、61库应用层及3876条逐条深度文本、51份来源映射和259段来源深化已接入。全部纳入词条已写成/执行方自审，另1误编号有依据排除，待写0条；原始60份TXT及38份历史稿保留，9份重复TXT不作日常主入口。四项授权收口均已独立验收通过，第四项R01修正已复核关闭。未做的全量独立词条复审、创作演练和媒体效果测试不自动列为任务。

默认协作：理解想法 → 查资料 → 分析 → 推荐与异议 → 与用户讨论 → 按用户指定进入制作 → 记录决定。

## 直接开始

技能已保存到 `本项目 skills/film-creation-library/`，名称为“AIGC创作小秘”。

新任务可以直接说：

```text
使用 $film-creation-library。我想做一部AIGC短剧，核心想法是……
先从相关语言库找依据，帮我分析方向、提出方案。
可以反对我的想法，但请说明理由，并给出可实行的替代。
```

换成音乐、图片、大纲或其他创作需求即可。无需先填写完整表单；AI主动补充方案、数据和理由。

## 完整首版的检查范围

第一项固定36工作流及整改、第二项38稿有效内容比较/条件整合、第三项15入口与所用资源关系已通过独立内容验收。61库3876条是写作与执行方自审齐备，3877候选含1有据排除；这些数字不等于全部原词条独立复审。工程检查验证检索、原文与路径，未做实际模型生成效果测试、15类创作演练和全量独立词条复审。实际创作按本次任务核实影响决策的疑点并记录结果。
