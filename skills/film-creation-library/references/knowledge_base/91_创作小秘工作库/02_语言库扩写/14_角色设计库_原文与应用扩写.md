四、角色一致性描述模板（20条）

61. 正面角色描述模板（Front Face Template）
定义：用于AI生成角色正面视角时的标准描述格式。
AI技术执行：按顺序描述，脸型、发型发色、眉形、眼形瞳色、鼻型、唇形、肤色、特殊标记、表情、头部比例。
情绪功能：标准化、可复现、一致性。
适用场景：角色首次建立、多镜头一致性控制、AI生成提示。

62. 侧面角色描述模板（Side Profile Template）
定义：用于生成角色侧面视角的描述格式。
AI技术执行：重点描述侧面可见特征，鼻梁高度和弧度、下巴轮廓、额头曲线、耳部位置和形状、脖颈线条、发型在侧面的表现。
情绪功能：多角度一致性、侧面美感。
适用场景：侧面镜头、剪影镜头、多角度角色展示。

63. 全身角色描述模板（Full Body Template）
定义：用于AI生成角色全身视角的完整描述。
AI技术执行：从头到脚完整描述，发型、面部、颈部、肩部、上身服装、手臂、腰部、下身服装、鞋子、身高体型、姿态、配饰。
情绪功能：完整形象、多镜头一致性、全身镜头。
适用场景：角色登场全身展示、全身镜头、服装展示。

64. 角色表情变化描述（Expression Variation Template）
定义：同一角色在不同情绪下的面部变化描述。
AI技术执行：保持基础五官不变，仅改变肌肉状态。同一角色，基础五官不变，此时情绪描述，眉毛变化，眼睛变化，嘴唇变化。
情绪功能：表情变化的一致性控制。
适用场景：多情绪镜头、表情连续性、角色表演。

65. 角色服装一致性描述（Costume Consistency Template）
定义：确保多镜头中服装保持一致的描述方法。
AI技术执行：服装按层次和颜色精确描述，标注关键辨识元素。上身穿颜色款式关键特征，下身穿颜色款式，外套颜色款式，鞋子颜色款式。
情绪功能：服装连续性、角色辨识度。
适用场景：多镜头叙事、时间连续性、服装特写。

66. 角色在不同光线下的描述（Lighting Adaptation Template）
定义：同一角色在不同光线环境下的描述调整。
AI技术执行：基础描述不变，增加光线适配。光线类型下，角色肤色呈现色调变化，服装颜色变暗或变亮或变色，面部阴影位置和形状。
情绪功能：光线一致性、真实感、氛围适配。
适用场景：不同场景的光线变化、昼夜切换、氛围变化。

67. 角色年龄变化描述（Age Progression Template）
定义：同一角色在不同年龄阶段的描述。
AI技术执行：保留核心五官特征，调整年龄特征。同一角色的年龄版本，面部皱纹或皮肤状态，体型变化，发型变化，姿态变化。
情绪功能：时间跨度叙事、角色成长、回忆或闪前。
适用场景：角色成长故事、时间跳跃、回忆场景。

68. 角色受伤状态描述（Injured State Template）
定义：角色受伤后的视觉描述。
AI技术执行：基础描述加受伤叠加。部位有伤口类型，大小或深度或出血量，服装破损描述，姿态因伤改变，面色苍白或潮红。
情绪功能：伤势可视化、真实感、紧迫感。
适用场景：战斗后、受伤场景、医疗场景、逃亡。

69. 角色战斗状态描述（Combat State Template）
定义：角色在战斗中的特殊状态描述。
AI技术执行：基础描述加战斗状态叠加。武器或能力在手，姿态进攻或防守或闪避，表情专注或愤怒或冷静，身体紧绷或放松或受伤，服装因动作而动的状态。
情绪功能：战斗动态、角色能力展示、紧张感。
适用场景：动作场景、战斗镜头、能力释放。

70. 角色特殊形态描述（Alternate Form Template）
定义：角色变身后或特殊形态的描述。
AI技术执行：基础特征部分保留加变化描述。保留核心辨识特征，变化身体大小或颜色或材质变化，服装变化或消失，出现新增元素如翅膀或角或光效或纹路。
情绪功能：变身、觉醒、力量释放、身份转换。
适用场景：变身场景、觉醒、特殊形态、能力爆发。

71. 角色与环境比例描述（Character-Environment Scale Template）
定义：角色在环境中比例关系的描述。
AI技术执行：明确角色在画面中的占比和与环境元素的相对关系。角色占画面比例，身高约为参照物的倍数，位于环境位置。
情绪功能：空间关系、角色大小感知、画面构图。
适用场景：大远景、环境展示、角色与环境关系。

72. 角色群像描述（Group Description Template）
定义：多个角色同时出现时的描述。
AI技术执行：先描述整体，再逐个描述关键区分特征。画面中有数量个角色。角色A最关键辨识特征；角色B最关键辨识特征；角色C最关键辨识特征。
情绪功能：群像辨识、多人场景、关系展示。
适用场景：群像镜头、团队展示、多人对话。

73. 角色背影描述（Back View Template）
定义：角色背面视角的描述。
AI技术执行：重点描述背面特征，后脑发型、背部服装细节、肩宽、腰部线条、腿部比例、配饰在背面的表现。
情绪功能：背影辨识、悬念、离别场景。
适用场景：背影镜头、离别、悬念、角色离场。

74. 角色剪影描述（Silhouette Template）
定义：角色剪影的辨识特征描述。
AI技术执行：忽略颜色和细节，只保留轮廓关键信息。剪影特征，发型轮廓形状，服装轮廓关键形状披风或裙摆或肩形，体型轮廓胖瘦或高低，标志性道具轮廓武器或帽子或翅膀。
情绪功能：剪影辨识、悬念、艺术感。
适用场景：剪影镜头、逆光场景、悬念揭示。

75. 角色特写描述模板（Close-up Template）
定义：角色面部或局部特写的描述。
AI技术执行：聚焦局部，忽略全身。部位特写，详细特征纹理或颜色或细节。
情绪功能：细节呈现、情绪放大、视觉冲击。
适用场景：面部特写、眼睛特写、手部特写、细节镜头。

76. 角色风格化描述（Stylized Character Template）
定义：特定艺术风格下的角色描述。
AI技术执行：先说明风格类型，再在风格框架内描述角色。风格名风格下的角色，风格化的五官或服装或比例描述。
情绪功能：风格统一、艺术表达、特殊视觉。
适用场景：风格化作品、艺术短片、特殊视觉风格。

77. 角色动作定格描述（Action Freeze Template）
定义：角色在动作瞬间的定格描述。
AI技术执行：捕捉动作的关键帧。动作名称的瞬间定格，身体姿态描述，手臂位置，腿部位置，头发或衣物飘动方向，面部表情，道具在位置。
情绪功能：动感、定格画面、视觉冲击。
适用场景：动作定格、海报式画面、关键瞬间。

78. 角色情绪状态描述（Emotional State Template）
定义：角色情绪状态的整体描述，含身体语言。
AI技术执行：面部表情加身体姿态加动作倾向。情绪状态，面部表情，身体姿态前倾或后仰或紧绷或放松，手部动作，整体氛围描述。
情绪功能：情绪整体呈现、角色内心外化。
适用场景：情感戏、角色状态展示、情绪高潮。

79. 角色关系视觉描述（Relationship Visual Template）
定义：两个或多个角色之间视觉关系的描述。
AI技术执行：相对位置加身体朝向加距离加互动。角色A与角色B，相对位置面对面或并肩或背对，距离亲密或个人或社交，身体朝向相对或一致或背离，互动动作对视或牵手或僵持。
情绪功能：关系可视化、亲密度、权力动态。
适用场景：双人对话、关系展示、群像互动。

80. 角色场景适配描述（Scene Adaptation Template）
定义：角色在不同场景中的适配描述。
AI技术执行：在场景描述中自然融入角色。场景描述中，角色穿着与场景匹配的服装，姿态与场景氛围匹配，与周围环境的互动描述。
情绪功能：场景融入、真实感、氛围统一。
适用场景：角色进入新场景、场景切换、环境互动。
