一、提示词基础（10条）

1. 主体描述
定义：提示词中描述主体是谁或什么。

定义：描述主体在做什么。
AI技术执行：动词明确，动作具体，可加动作方向、速度、幅度。
情绪功能：动态、叙事、具体。
适用场景：动作场景、战斗、日常。

情绪功能：风格统一、艺术表达。
适用场景：所有风格化提示词。

定义：描述镜头的景别、角度、运镜。
AI技术执行：远景、中景、近景、特写，平视、俯视、仰视，推拉摇移升降环绕。
情绪功能：镜头语言、视觉引导。
适用场景：电影感提示词、分镜。

6. 光线描述
定义：描述画面的光线设计。
AI技术执行：硬光、柔光、高调、低调、侧光、逆光、顶光、底光、自然光、人造光。
情绪功能：光影氛围、戏剧性、真实感。
适用场景：所有提示词的光线部分。

适用场景：所有提示词的画质部分。

定义：描述不要出现的内容。

情绪功能：质量控制、防错。
适用场景：所有提示词的反提示部分。

二、提示词语法（10条）

11. 权重
定义：控制提示词中某元素的权重。
AI技术执行：(word:1.5) 增加权重，(word:0.5) 降低权重，权重范围通常0.1-2。
情绪功能：强调、控制。
适用场景：需要强调或弱化某元素时。

12. 否定
定义：排除某元素。
AI技术执行：[word] 或 negative prompt 或 --no word。
情绪功能：排除、控制。
适用场景：不想要某元素时。

13. 强调
定义：强调某元素。
AI技术执行：(word) 或 !word 或 word!!! 或用权重增加。
情绪功能：强调、突出。
适用场景：需要突出某元素时。

14. 混合
定义：混合两个概念。
AI技术执行：[word1:word2:0.5] 表示前50%用word1，后50%用word2。
情绪功能：过渡、变化、混合。
适用场景：需要渐变或混合效果时。

15. 交替
定义：交替使用两个概念。
AI技术执行：[word1|word2] 交替出现。
情绪功能：变化、节奏、动态。
适用场景：需要交替变化时。

16. 分层
定义：按前景、中景、后景分层描述。
AI技术执行：前景描述 + 中景描述 + 后景描述。
情绪功能：空间深度、层次感。
适用场景：复杂场景、电影感画面。

17. 顺序
定义：提示词的排列顺序。
AI技术执行：通常主体在前，环境在后，风格在最后。
情绪功能：清晰、可控。
适用场景：所有提示词的基础结构。

18. 具体
定义：使用具体而非模糊的描述。
AI技术执行：避免"美丽""好看"，使用"红发蓝眼高鼻梁"等具体描述。
情绪功能：精准、可控。
适用场景：所有提示词的精度控制。

19. 一致
定义：提示词中的风格、光线、色彩保持一致。
AI技术执行：所有描述元素之间不矛盾，风格统一。
情绪功能：统一、可控。
适用场景：多镜头一致性控制。

20. 简洁
定义：避免冗余和重复。
AI技术执行：删除不必要的描述，保留核心信息。
情绪功能：清晰、高效。
适用场景：所有提示词的优化。
