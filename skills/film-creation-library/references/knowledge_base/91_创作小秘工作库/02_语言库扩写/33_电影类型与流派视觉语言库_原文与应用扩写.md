一、黑色电影（Film Noir）（5条）

1. 黑色电影核心视觉（Film Noir Core Visual）
定义：1940-1950年代好莱坞犯罪片的标志性视觉风格，以阴暗、宿命和道德模糊为核心。
AI技术执行：高对比度黑白摄影，低调光为主，大量阴影覆盖画面阴影占比50-70%，百叶窗投影，烟雾弥漫，雨夜街道，人物在阴影中若隐若现，构图不平衡，荷兰角常见。
情绪功能：阴暗、宿命、道德模糊、危险、压抑。
适用场景：犯罪片、侦探片、悬疑、黑色电影、心理惊悚。

2. 黑色电影人物（Film Noir Character）
定义：黑色电影中的典型人物视觉特征。
AI技术执行：男主角穿风衣戴软呢帽，口中叼烟，面容疲惫冷峻，常在阴影中；女主角为蛇蝎美人，金发或黑发，浓妆红唇，穿着性感，眼神危险，常在烟雾中。
情绪功能：危险、诱惑、疲惫、宿命、道德模糊。
适用场景：黑色电影、犯罪、侦探、蛇蝎美人、宿命。

3. 黑色电影光影（Film Noir Lighting）
定义：黑色电影特有的光影设计。
AI技术执行：低调光为主，光源单一且方向性强如路灯、窗户、手电筒，大量阴影覆盖，百叶窗投影在人物面部，烟雾中的光束丁达尔光，明暗对比强烈光比1比8以上。
情绪功能：压抑、危险、神秘、宿命、不安。
适用场景：黑色电影、犯罪、悬疑、心理惊悚、压抑。

4. 黑色电影场景（Film Noir Setting）
定义：黑色电影的典型场景。
AI技术执行：雨夜街道湿地面反射霓虹或路灯，昏暗酒吧，烟雾缭绕的办公室，狭窄公寓，阴暗码头，霓虹灯牌闪烁，整体呈现都市的阴暗面。
情绪功能：都市、阴暗、危险、孤独、压抑。
适用场景：黑色电影、犯罪、都市、夜生活、阴暗。

5. 黑色电影构图（Film Noir Composition）
定义：黑色电影特有的构图方式。
AI技术执行：不平衡构图，荷兰角15-45度，人物被阴影分割，前景遮挡百叶窗、烟雾、栅栏，镜像反射，隧道透视，人物在画面边缘或被挤压。
情绪功能：不安、失衡、被困、压抑、危险。
适用场景：黑色电影、心理惊悚、犯罪、悬疑、不安。
