# 表演、微表情与群体动作

## 输入与需求理解

人物目标、台词、当前关系、身体状态、景别和剧情转折。

## 分析方法

按行动目标识别触发、反应、抑制、恢复和潜台词；多角色各有响应，背景群体分层。

## 方案应包含什么

表演方向、可见动作、节奏变化、强度选择、面部与对白协调、需要用户选择的审美差异。

## 什么情况下应提出异议

情绪标签替代行动；口型被持续抿唇覆盖；远景要求不可见毫米细节；强制推断掩饰台词的唯一真实情绪。

## 用户指定进入制作后

输出时间化物理表演序列，包含肌肉/五官、呼吸、视线、动作与结束状态。

## 验证要点

动作可读、方向相容、口型与表情共存、群体数量路径明确，不从表情作心理诊断。
