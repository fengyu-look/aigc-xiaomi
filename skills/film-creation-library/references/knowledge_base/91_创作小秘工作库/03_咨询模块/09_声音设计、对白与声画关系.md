# 声音设计、对白与声画关系

## 输入与需求理解

画面事件、环境、人物声线、台词、声音视点与现有音频。

## 分析方法

区分远近、剧情声源和非剧情配乐，选择同步、声音先入、延续或对位。

## 方案应包含什么

声源与空间、轨道层次、触发时间、台词节奏、混响方向、静音方式及相应理由。

## 什么情况下应提出异议

环境不同却同一混响；静音定义含糊；脚步未接触就发声；对白被配乐遮蔽。

## 用户指定进入制作后

输出逐事件声音提示词、配音清单或混音方案；有素材时按实际听到的内容诊断。

## 验证要点

声源方位、接触同步、台词准确、环境承接和声音切点明确，未测数据不当实测。

### 具体交付和上下游

- **交付**：咨询交付声源/空间与声画方案；授权后交逐事件声音提示、逐字配音清单、轨道/时间/混响/尾音及选择的混音设计。
- **上游**：接画面事件、D/V原句、发声者与听者、声源方位、场景材质、人物知识、音频可访问范围和全片时间映射。
- **下游**：给music传对白占用窗口/叙事音乐功能；给video/post传AUDIO/声轨ID、局部/全片起止、尾音跨切、静音类型与媒介知情末态。设计分贝不当测量值，未听音轨不称已诊断。
- **持续依据**：依技能 `references/project_state.md` 保存当前有效成果版本、覆盖/下一单元、已确认与设计/待定分别记录、进入/退出状态及改动传播。项目目录沿用用户位置，作品不写回公共语言库；单次咨询不强建空项目。
- **继续与修改**：继续读取当前授权范围和对应故事线最近有效末态，缺后文不编原著续篇；修改先重出完整受影响单元，再同步必须传播的资产、知识、声轨与时间线，已完成无影响部分保留。
- **检查口径**：来源/参数/文本自审与实际生成结果分别标注，未访问、未生成、未试听不写成已验证。
