# 不可违背原则
1. 人眼不是相机：必须有视野边缘模糊、焦点转移延迟、瞳孔适应、泪膜光晕、眼睑遮挡、盲点感。
2. 身体不是稳定器：必须有呼吸导致的画面轻微起伏、心跳、吞咽、衣物摩擦、鼻息、温度或皮肤触感。
3. 眨眼必须可执行：自然眨眼每 5-8 秒一次，闭合 0.1-0.15 秒；轻度紧张每 4-5 秒一次；高度紧张每 3-4 秒一次；专注每 8-10 秒一次；疲惫每 6-8 秒一次，闭合 0.2 秒；悲伤每 5-6 秒一次，闭合后黑场略长 0.2-0.3 秒；震惊暂停 2-3 秒，随后快速眨 1 次。每个 10-12 秒分镜眨眼总数控制在 1-2 次，高度紧张最多 3 次。禁止每 1-2 秒眨眼。眨眼时画面短暂黑场或眼睑遮挡，伴随轻微闭眼湿润声。
4. 呼吸必须可执行：写出呼吸频率、吸气/呼气时长、胸腔或肩膀起伏幅度、呼吸声类型。

6. 吞咽必须可执行：写出吞咽次数、喉咙动作、发生时间点。

# 分镜收尾完整性与切镜衔接系统
每个分镜必须独立输出“分镜收尾完整性与切镜衔接校验”，用于确保分镜内部完整、分镜之间衔接合理。校验必须覆盖以下 9 类规则，每类必须写明校验结果：通过 / 不通过 / 不适用。若不通过，必须写明修复方案，并同步修改分镜正文与 Seedance 提示词。

## 收尾规则 1｜动作完成态
- 每个分镜结尾，主体正在执行的动作必须已经完成。
- 禁止动作停留在中途：手伸到一半、门推到一半、身体转到一半、视线移到一半。
- 允许的完成态：手已收回、门已推开、身体已转正、视线已落定、脚步已站稳、物品已放下、衣物已整理好。
- 若动作必须跨分镜，必须在本分镜末尾标注“动作延续”，并写明延续的具体状态：手已伸至门把手但尚未转动、门已推开一条缝但尚未完全打开。
- 负向提示词追加：不要动作中途结束，不要手伸到一半，不要门推到一半，不要身体转到一半，不要视线移到一半。

## 收尾规则 2｜尾帧静止可读
- 每个分镜的尾帧必须是一个静止可读的画面。
- 尾帧必须能独立描述：主体可见部分位置、物体位置、光源、色彩、影子、宏观氛围。
- 禁止尾帧画面模糊、抖动、错位、残缺。
- 若为连续衔接，尾帧必须与下一分镜首帧连续；若为切镜衔接，尾帧不要求与下一分镜首帧连续，但仍必须静止可读。
- 负向提示词追加：不要尾帧模糊，不要尾帧抖动，不要尾帧错位，不要尾帧残缺。

## 收尾规则 3｜分镜衔接方式明确
- 每个分镜必须明确标注与下一分镜的衔接方式：连续衔接 或 切镜衔接。
- 连续衔接：本分镜尾帧与下一分镜首帧在主体可见部分位置、物体位置、光源、色彩、影子、宏观氛围、情绪、生理状态上连续。
- 切镜衔接：本分镜尾帧与下一分镜首帧不要求连续。必须写清切镜类型、切镜点、切镜后的新场景、新时间、新视角或新情绪状态。
- 切镜类型包括：硬切、淡入淡出、叠化、黑场、白闪、声音先入、画面先出、匹配剪辑、动作衔接切、情绪反差切。
- 禁止切镜未标注、切镜突兀、切镜后状态混乱。
- 负向提示词追加：不要切镜未标注，不要切镜突兀，不要切镜后状态混乱，不要连续衔接与切镜衔接混淆。

## 收尾规则 4｜情绪收束
- 每个分镜结尾情绪必须收束到明确状态。
- 禁止结尾情绪模糊、情绪中断、情绪矛盾。
- 若为连续衔接，情绪收束必须与下一分镜开头情绪连续。
- 若为切镜衔接，情绪可以跳跃，但必须写清切镜后的新情绪状态。
- 负向提示词追加：不要情绪模糊，不要情绪中断，不要情绪矛盾，不要情绪跳跃未标注。

## 收尾规则 5｜生理收束
- 每个分镜结尾生理状态必须收束到明确状态。
- 生理收束包括：呼吸频率、心跳 BPM、吞咽状态、眨眼状态、衣物摩擦状态。
- 若为连续衔接，生理收束必须与下一分镜开头生理状态连续。
- 若为切镜衔接，生理状态可以变化，但必须写清切镜后的新生理状态。
- 负向提示词追加：不要生理状态模糊，不要生理状态中断，不要生理状态矛盾，不要生理状态跳跃未标注。

## 收尾规则 6｜声音收束
- 每个分镜结尾声音必须收束到明确状态。
- 声音收束包括：环境音、人声、生理音、混响、声场。
- 若为连续衔接，声音收束必须与下一分镜开头声音连续。
- 若为切镜衔接，声音可以变化，但必须写清切镜后的新声音状态，包括切镜瞬间的声音处理（硬切、淡出、声音先入等）。
- 若结尾有静音，必须写明静音开始时间点与持续时长。
- 负向提示词追加：不要声音模糊，不要声音中断，不要声音矛盾，不要声音跳跃未标注。

## 收尾规则 7｜空间收束
- 每个分镜结尾空间关系必须收束到明确状态。
- 空间收束包括：物体位置、人物位置、遮挡关系、透视、比例。
- 若为连续衔接，空间收束必须与下一分镜开头空间关系连续。
- 若为切镜衔接，空间可以跳转，但必须写清切镜后的新空间关系。
- 若结尾有物体移动，必须写明移动完成位置。
- 负向提示词追加：不要空间关系模糊，不要空间关系中断，不要空间关系矛盾，不要空间关系跳跃未标注。

## 收尾规则 8｜动作延续标注
- 若动作必须跨分镜延续，必须在本分镜末尾明确标注“动作延续”。
- 动作延续必须写明：延续的动作、延续的状态、延续的时间点、下一分镜应从此状态开始。
- 下一分镜开头必须复述动作延续状态，并确认连续。
- 若为切镜衔接，动作延续可以在切镜后重新开始，但必须写清切镜后的新动作起点。
- 负向提示词追加：不要动作延续未标注，不要动作延续状态模糊，不要下一分镜从半截动作开始。

## 收尾规则 9｜切镜衔接信息完整
- 若为切镜衔接，必须写清以下信息：
  - 切镜类型：硬切 / 淡入淡出 / 叠化 / 黑场 / 白闪 / 声音先入 / 画面先出 / 匹配剪辑 / 动作衔接切 / 情绪反差切。
  - 切镜点：本分镜第几秒切出，下一分镜第几秒切入。
  - 切镜后的新场景、新时间、新视角、新情绪状态、新生理状态。
  - 切镜瞬间的声音处理方式。
- 负向提示词追加：不要切镜信息缺失，不要切镜类型模糊，不要切镜点模糊，不要切镜后新状态模糊。

# 逻辑一致性校验系统
每个分镜必须独立输出“逻辑一致性校验”，用于在生成前主动排查并消除 AI 视频常见逻辑错误。校验必须覆盖以下 12 类逻辑链，每类必须写明校验结果：通过 / 不通过 / 不适用。若不通过，必须写明修复方案，并同步修改分镜正文与 Seedance 提示词。

## 逻辑链 1｜动作因果链
- 每个动作必须有前因、执行、结果。
- 禁止结果先于原因。
- 禁止动作无触发。
- 禁止动作跳跃。
- 示例：先看到门虚掩（因）→ 停住呼吸（反应）→ 伸手推门（执行）→ 门轴响（结果）→ 视线进入客厅（新状态）。

## 逻辑链 2｜空间关系链
- 物体与物体之间、人物与人物之间、人物与物体之间的位置必须自洽。
- 禁止同一物体在同一时间出现在两个位置。
- 禁止物体穿透另一物体。
- 禁止人物穿过墙体、门板、家具。
- 禁止物体漂浮无支撑。
- 禁止影子方向与光源方向矛盾。
- 禁止遮挡关系在同一分镜内反转而无动作解释。

## 逻辑链 3｜物理规律链
- 重力方向一致。
- 物体下落、滚动、倾倒符合物理。
- 液体流动方向正确。
- 布料下垂方向正确。
- 头发、衣摆、烟雾、尘埃运动方向与风、呼吸、动作一致。
- 光源照射方向与高光、阴影方向一致。
- 禁止物体凭空出现或消失。
- 禁止手穿过物体。

## 逻辑链 4｜时间顺序链
- 子镜头时间轴必须严格递增。
- 每个动作必须在合理时长内完成。
- 禁止动作时长与速度矛盾。
- 禁止同时发生互斥动作。
- 禁止上一子镜头未结束的动作在下一子镜头凭空完成。
- 眨眼、呼吸、心跳、吞咽必须按真实生理节奏分布。

## 逻辑链 5｜人物交互链
- 人物与人物之间的视线、动作、对话、距离必须自洽。
- 禁止两人同时占据同一空间。
- 禁止一人对另一人动作无反应。
- 禁止对话口型与声音方位矛盾。
- 禁止人物身份、服装、外貌在同一分镜内变化。
- 禁止多人场景人物数量突变。
- 禁止人物关系错误。

## 逻辑链 6｜数量与身份链
- 每个分镜中人物数量、物体数量必须明确且一致。
- 禁止人物数量增减无解释。
- 禁止物体数量增减无解释。
- 禁止同一人物被描述为不同身份。
- 禁止背景人物突然消失或出现。
- 禁止镜像、倒影中人物数量与实体矛盾。

## 逻辑链 7｜环境与道具链
- 环境中的物体必须符合时代、地域、社会背景。
- 禁止现代物品出现在古代场景。
- 禁止古代物品出现在现代场景。
- 禁止室内出现室外天气。
- 禁止道具位置无解释变化。
- 禁止道具材质、颜色、状态在同一分镜内突变。
- 禁止光源类型与场景矛盾。

## 逻辑链 8｜视线与注意力链
- 主体视线方向必须与当前焦点一致。
- 禁止看向 A 却描述 B。
- 禁止焦点转移无触发。
- 禁止余光区域描述超出人眼视野范围。
- 禁止大脑过滤区域出现细节。
- 禁止主体看到自己面部。

## 逻辑链 9｜生理与情绪链
- 生理参数必须与情绪匹配。
- 禁止紧张时心跳低于平静值。
- 禁止恐惧时呼吸平稳。
- 禁止疲惫时动作敏捷。

# 第一人称 POV 物理约束系统
每个分镜必须独立输出“第一人称 POV 物理约束校验”，用于在生成前主动排查并消除 AI 视频中第一人称视角常见错误。校验必须覆盖以下 10 类约束，每类必须写明校验结果：通过 / 不通过 / 不适用。若不通过，必须写明修复方案，并同步修改分镜正文与 Seedance 提示词。

## POV 约束 1｜主体头部禁止出现
- 第一人称 POV 下，画面中禁止出现主体自己的头部、脸、头发、后脑勺、肩膀、脖子、耳朵、下巴。
- 禁止出现越肩视角、第三人称视角、旁观者视角。
- 禁止出现主体自己的完整面部或半张脸。
- 允许出现：鼻子尖极淡轮廓（仅在强光或极近物体时）、呼吸导致的下巴边缘极淡遮挡（仅在下垂视线时）。
- 默认处理：主体面部与头部完全不出现。若剧情必须出现，必须明确标注“例外”，并写出理由与画面处理方式。
- 负向提示词追加：不要主体头部，不要主体面部，不要主体头发，不要主体后脑勺，不要主体肩膀，不要主体脖子，不要主体耳朵，不要主体下巴，不要越肩视角，不要第三人称视角。

## POV 约束 2｜主体可见身体限制
- 第一人称 POV 下，主体只能看到以下身体部分：
  - 手、手指、手腕、前臂、上臂（部分）
  - 腿、膝盖、脚、鞋（向下看时）
  - 胸口、腹部（向下看时）
  - 衣物：袖口、前襟、裤腿、鞋面、裙摆
  - 影子、倒影、反射中的自己
- 禁止出现：完整躯干、完整双腿、完整手臂、背影、侧面全身。
- 若剧情需要看到身体，必须通过镜子、窗户反射、水面倒影、屏幕反射，且必须标注媒介类型与位置。
- 负向提示词追加：不要完整躯干，不要完整双腿，不要完整手臂，不要背影，不要侧面全身。

## POV 约束 3｜视线高度与角度锁定
- 第一人称 POV 下，视线高度必须与主体身高一致。
- 视线角度必须与头部转动角度一致，且转动幅度受颈部限制。
- 禁止视线瞬间跳到不可能的角度。
- 禁止视线从天花板直接跳到地板而无中间过渡。
- 禁止视线穿过墙体、门板、家具。
- 视线转移必须有时间、有方向、有速度。
- 负向提示词追加：不要视线跳跃，不要视线穿墙，不要视线穿模，不要视线高度错误，不要视线角度错误。

## POV 约束 4｜物体位置锁定
- 每个物体在分镜内必须锁定唯一位置。
- 禁止同一物体在同一分镜内出现在两个位置。

- 禁止物体位置与上一分镜连续性锁定矛盾。

- 负向提示词追加：不要物体位置漂移，不要物体位置突变，不要物体重复出现，不要物体消失，不要物体瞬移。

## POV 约束 5｜物体穿透与穿模防护
- 禁止物体穿透另一物体。
- 禁止人物穿过墙体、门板、家具、玻璃。

- 禁止物体与物体重叠冲突。

- 每个物体必须标注画面坐标、深度、相对主体位置、相对其他物体位置。

- 遮挡关系必须明确：谁在前、谁在后、谁遮谁。

- 透视必须统一，禁止同一画面内出现多个透视消失点。
- 物体比例必须自洽，禁止近大远小错误。

- 负向提示词追加：不要透视矛盾，不要多消失点，不要比例错误，不要近大远小错误，不要头身比例突变，不要物体大小突变，不要广角畸变，不要鱼眼畸变。

## POV 约束 10｜主体影子与倒影自洽
- 主体自身可见部分必须有影子，或说明无影子原因。
- 主体影子方向必须与光源方向相反。

# 高级强制规则

## 补丁 1｜音频空间深度
每个分镜的听觉层必须写清：

- 子镜头 2｜00:03-00:06：
- 子镜头 3｜00:06-00:09：
- 子镜头 4｜00:09-00:12：

要求：子镜头之间必须有因果或动作连续，不能跳跃。

## 补丁 11｜输出校验清单
每个分镜末尾必须输出“本分镜校验清单”，包含全部逻辑链校验、POV 约束校验、分镜收尾完整性与切镜衔接校验、宏观校验结果。

## 细节 1｜视觉拖影
快速视线转移时，画面出现 0.1 秒方向性拖影。

## 细节 2｜近焦切换
手部进入画面时，焦点从远景延迟 0.3 秒切换到近景，手部先模糊后清晰。

## 细节 3｜主体自身呼吸声左右声道
吸气时偏鼻腔后方，呼气时偏口腔前方，心跳偏左后方，吞咽偏喉咙中央。

# 宏观提示词强制规则
每个分镜必须单独写“宏观提示词”，用于控制整段视频的风格、时代、情绪、色彩、光线、声音基调。宏观提示词必须与原文匹配，并在同一分镜内保持稳定。若剧情内发生时代跳跃、回忆、梦境、想象，必须明确标注宏观提示词切换的时间点与切换后的新宏观设定。

每个分镜的宏观提示词必须包含以下字段：
- 风格：真实电影 / 纪录片 / 手持纪实 / 黑色电影 / 赛博朋克 / 古典文艺 / 恐怖惊悚 / 青春治愈 / 其他。必须写清参考质感、颗粒、锐度、景深倾向。
- 时代背景：具体年代或架空时代，如“当代都市 2020 年代”“民国时期”“近未来 2040”“古代架空”。必须写清科技水平、社会氛围、服饰特征、建筑风格、道具年代。
- 地域与社会环境：国家、城市、区域、社会阶层、文化圈。必须写清建筑、街景、室内装修、公共设施、人群氛围。
- 情绪氛围：整体情绪基调，如“疲惫警觉”“压抑不安”“温柔怀念”“紧张窒息”“孤独疏离”。必须写清情绪曲线：开头、中段、结尾分别是什么情绪，是否递进。
- 色彩氛围：主色调、辅助色、色温、饱和度、对比度、色彩象征。如“冷绿与暗黄”“低饱和莫兰迪”“蓝黑冷调”“暖橙回忆”。必须写清颜色在画面中的占比与变化。
- 光线氛围：自然光 / 人工光 / 混合光；光源方向、强度、色温、阴影硬度；是否有体积光、光斑、闪烁、过曝、暗角。
- 声音氛围：环境声基调、混响类型、音乐情绪、是否有低频嗡鸣、耳鸣、静音段。必须写清声音与情绪的关系。
- 文化/地域元素：语言、口音、习俗、宗教、符号、禁忌、时代特有物件。
- 整体视觉参考：可写参考影片、摄影风格、画派、胶片型号、镜头质感，但禁止使用相机术语。
- 本分镜情绪曲线：按子镜头时间轴写出情绪变化：00:00-00:03、00:03-00:06、00:06-00:09、00:09-00:12 分别是什么情绪。

宏观提示词必须进入 Seedance 正向提示词、首帧提示词、尾帧提示词、关键帧提示词，并按优先级放在“第一人称 POV 物理约束声明”之后。
