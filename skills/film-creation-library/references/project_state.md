# 项目决定与连续状态

仅在多镜头、多集、持续歌曲/图集或已有项目需要保存时使用，沿用用户目录；单次咨询不创建大批空文件。

建议在项目的`当前状态.md`记录：

- 项目目标、当前阶段、已确认形式和风格。
- 素材路径、版本、已覆盖/未覆盖内容、完成的单元编号。
- 已确定、待讨论、已放弃的方案及其原因；用户确认与AI建议明确区分。
- 人物、场景、道具、音色/音乐动机固定ID和参考资产作用。
- 当次服装、姿态、位置、持有者、数量、光源、天气、时间、损伤与不可逆变化。
- 上单元结束状态、下单元起点，连续或时空转换；声音是否延续。
- 使用的库号/词条、工作流来源、重要设计值及修改影响。
- 实际生成结果的有效与失效证据，以及下一步需要用户决定什么。

用户说“继续”时读取相关交接，沿当前阶段和授权推进，不把“继续讨论”解释成自动制作全部作品。不重做已完成内容，不无故推翻已确认方向。

公共资料的更新不自动改变项目事实；草案不能自动变成确认结果。按已有版本习惯保存成果，未经明确要求不删除历史稿。用户要求只保留当前版本时，先完成核对再替换相关文件。


## 可恢复的交接记录

沿用已有状态文件和版本习惯，只补本次需要的字段；以下是记录口径，不要求用户填写完整问卷。状态来自已确认决定、当前有效文本和实际素材，分别标来源事实/推断/AI设计/待定/实际验证。

| 记录 | 当前必须表达的信息 |
| --- | --- |
| 授权与游标 | 当前分析/比较/制作范围、用户已授权交付、当前主模块与条件版本、已完成单元、待做单元、下一未覆盖原句/镜头/小节 |
| 版本与来源 | 一份当前有效成果路径/版本、素材实文件与版本、所用SourceId/HistoryId/TaskId及行段；历史稿保留，分支按用户需要创建 |
| 固定身份与资产 | CHAR/SC/PROP/REF或现有固定ID；身份骨架/固定地图、实际参考图脸/衣/空间/光色职责、设计稿/已生成/已验收状态 |
| 当次进入与退出 | 人物阶段、位置/朝向/姿态/支撑脚、视线与呼吸相位、服装/伤湿/疲劳、道具持有人/手侧/数量/位置/液面、场景光源/天气/时间 |
| 信息与不可逆结果 | 各角色知识及知情渠道、观众旁白、未知真假、关系/伤损/死亡/损坏/消耗/痕迹；录制/保存/发送/播放/听到分别记 |
| 时间与声音 | 原发生/原叙述/作品呈现时间，SC/SHOT/GEN或实际单元ID、局部0起点到全片映射、帧率/变速，D/V/AUDIO/MUSIC原句、声源/听者、尾音与静音类型 |
| 结果与下一步 | 实际可访问结果、有效/失败证据、尚未生成/试听/导出、下一单元起点、真正待用户决定项；未核数据不作实测 |

### 按操作读取状态

- **继续**：核本次授权→读当前有效版本和覆盖游标→取对应线最近有效退出状态→接下一未完成单元。已交付动作不重演；当前要求继续讨论时继续分析，不自动制作；已授权完整交付可持续完成，不人为每镜再问。
- **修改**：明确用户新要求的生效范围，定位受影响单元并重出其完整有效稿；登记“直接修改/必须同步/建议复核/不变”。身份外观改变同步相应参考和生成文本，道具归属改变同步后续动作，知识揭示改变同步后续对白，时长改变同步全片与声轨。只更新实际修改/检查的范围，未检查不能称全片已同步。
- **跨批次/换故事线**：保留已覆盖原句、场/镜/生成单元、下一句与该线最近有效末态；不要用上一批最后出现的另一线角色状态覆盖本线。单块生成正文写全必要状态，状态文件可以引用版本，生成块不能只写“见前文”。
- **回退**：恢复对应成果、信息/道具/关系/时间/声轨账本；不只回对白却留下后来知道的秘密或后来破损资产。库更新不改写已确认项目事实。
- **交互分支**：每个NODE/BRANCH记录进入条件、选择、状态增量、结果和合流守卫。道具归属/角色知识等末态不同不能直接合为相同状态；未建立可达路径不称分支实现成功。

### 模块间传递

策划传目标/所选方向和当前授权；小说传原句/章节、世界/关系/知识；剧本传SC/B/D/V覆盖及事实/权限；图片传实体/参考版本与固定/当次状态；分镜传SHOT/GEN、首帧和起终、局部/全片时间；视频传独立生成块、实际TAKE结果及失败对象；表演传人物各自动作/口型/视线时间；打斗传接触链/资源消耗/伤损；声音传声源/媒介/尾音；音乐传DNA/小节秒数/歌词时窗；商业传产品/文案证据与真实素材门；剪辑传素材入出点/变速/导出证据；三维交互传坐标尺度和分支守卫；反推传可访问模态与观察证据；框架维护传新旧对应与条件版本。每类具体资源选择和上下游字段以该模块的“当前流程选择与交接”节为准。

用户只要单次分析时可在答复中记录必要决定；持续制作才保存项目状态。作品、素材、实际结果放用户指定作品项目，不能混入Skill公共知识库。
