# 原框架保留与逐条扩写规范

库级扩写和逐词条深度扩写分开记录。原文完整保存，不以摘要替代原文，不把“模板已接入”记成“模板各步骤已深化”。

对每个词条或步骤，按实际内容补充：

1. 要解决的具体创作问题、适用条件、不适用条件。
2. 输入信息、前置状态、执行对象、方向、幅度、速度、持续时间与结束状态；音乐对应节奏、乐句、和声、配器和结构。
3. 原文数值与AI设计值的单位、依据、调整范围和相互核对。无法从素材测得的数值不得伪装成测量事实。
4. 当前任务可复制的完整例子，包含明确角色/空间/声音或音乐结构。不能只写“参见某库”。
5. 常见失败、哪些条件会造成失败、怎样修正；与哪些词条组合、哪些组合可能冲突。
6. 该条内容来自哪里、哪些观点已核实、哪些仍属设计建议、实际生成验证了什么。

不是每条都机械堆同样长度。保留原有字段，再针对该条真正的缺口丰富。用户决定风格与关键方向，AI主动提出普通细节与精确参数。

原文参数存在矛盾时，保留来源、指出矛盾，在扩写层解释纠正或备选；不悄悄修改保留原文。技术版本、解剖、光学、历史等影响本次结论的事实按适当权威来源核实。

“完成”需有逐条覆盖记录和可检查内容；“已验证有效”需有真实素材/生成结果。只有原文转MD或增加全库通用说明的条目，不能按此标准标记深度扩写完成。
