# 部署、迁移与日常使用

## 一个维护源

项目里的 `skills/film-creation-library/` 是完整技能，包含全部参考知识库。桌面项目为本机维护源；旧E盘和旧桌面“提示词”保留作来源备份，后续扩写、工具和文档都维护在本项目。

技能脚本按自身文件位置寻找 `references/library_config.json`，再按技能目录解析相对资料路径。不需要改盘符，也不依赖从哪个目录启动命令。

## 部署方式

`python tools/deploy_skill.py --mode link` 将完整技能链接到技能发现目录。默认使用 `CODEX_HOME/skills`；未设置时使用当前用户的 `.codex/skills`。可用 `--skills-dir` 指定宿主要求的目录。

Windows链接方式为目录联接；其他系统为符号链接。项目移动后，旧链接不会自动追踪新位置，需要在新位置重新执行部署。桌面中的改动则立即作用于同一链接目标。

`--mode copy` 复制完整技能，包含内置知识库，移动源项目后部署副本仍可读取。修改源项目后需重新部署更新副本。

同名目标已存在时默认停止，不删除文件。`--replace` 把旧入口移动到 `.local/部署备份/` 后替换；失败时尝试恢复旧入口。`--dry-run` 只展示计划。

## 迁移检查

```shell
python tools/check_project.py
python -m unittest discover -s tests -v
```

测试包括另一目录中的独立Skill复制、非项目工作目录启动、知识库检索、错误路径、缺失索引、过期MD偏移与部署备份。它们验证文件和工具，不代替真实创作任务的效果评估。

## 如何查资料

```shell
python skills/film-creation-library/scripts/library_lookup.py route --query "想做一首音乐"
python skills/film-creation-library/scripts/library_lookup.py read --module music
python skills/film-creation-library/scripts/library_lookup.py search --query "和声" --library 43
python skills/film-creation-library/scripts/library_lookup.py catalog --kind history
python skills/film-creation-library/scripts/library_lookup.py search --scope history --query "BGM"
```

默认搜索61个工作库，可用 `--scope workflows/history/all` 扩大范围。结果只是定位，正式采用前读取前后正文和新增指导，并说明来源。

## 扩写后维护

```shell
python tools/refresh_index.py --dry-run
python tools/refresh_index.py
python tools/check_project.py
```

索引刷新依据原始TXT/合集验证原文块未改变，然后更新当前MD哈希和偏移；找不到完整原文时拒绝刷新。词条深度扩写进度由实际编写与审核维护，刷新索引不会自动变成“全部完成”。

部署目录与文件格式依据[官方Skill文档](https://developers.openai.com/codex/skills/)。不同宿主的发现路径以其实际配置为准；本机保留当前已使用的发现目录。
